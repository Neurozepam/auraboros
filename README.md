# Auraboros

Десктопное пространство для обучения с AI: курсы из вашей цели, уроки на свободном холсте, проверки знаний и суб-уроки.

## Скачать

Первая версия для **Windows x64**: [v0.0.1 — alpha](https://github.com/Neurozepam/auraboros/releases/tag/v0.0.1).

Скачайте `Auraboros-v0.0.1-windows-x64.zip`, распакуйте целиком и запустите `Auraboros/Auraboros.exe`. Соседняя папка `_internal` нужна для работы приложения. Python и Node.js уже включены в поставку.

Подключение ChatGPT/Codex или Claude выполняется в приложении через аккаунт провайдера. Нужны интернет и доступ к выбранной модели. Курсы и история хранятся локально на вашем устройстве.

## В первой версии

- Генерация и редактирование плана курса.
- Уроки в отдельных Spaces, потоковые ответы и тесты.
- Дополнительные вопросы и отдельные суб-уроки.
- Перемещение блоков, зум и навигация по холсту.
- Локальное сохранение курсов, истории и черновиков.

Ответить на открытый вопрос AI пока можно через «+ вопрос» под его блоком → «Отправить». Автообновление, граф знаний, исполнение кода и автоматический фактчекинг запланированы на следующие версии.
